# Incident Handler's Journal

### 📋 Overview
I documented six cybersecurity incident scenarios using an incident handler’s journal format. Each entry analyzes a different security incident by documenting the 5 W’s (Who, What, Where, When, and Why), along with the incident description, tools used, additional notes, and personal reflections. This activity helped develop skills in incident documentation, security analysis, and understanding the incident detection and response process.

### 🛠️ Key Skills Demonstrated
* **Incident Documentation:** Recording security incidents using a structured incident handler journal format.
* **Incident Analysis:** Investigating incidents by identifying key details using the 5 W’s framework.
* **Threat Response Process:** Understanding how security teams document, analyze, and respond to incidents.
* **Security Tools:** Documenting tools and resources used during incident investigation activities.
* **Analytical Thinking:** Reflecting on challenges, lessons learned, and improvements in incident detection and response knowledge.
